# by-hand

A Claude Code plugin marketplace for learning by doing: you type, Claude teaches.

| Plugin | What it is |
|---|---|
| [lab-instructor](https://github.com/MuathIbnHassan/lab-instructor) | Claude as a hands-on lab instructor for any technical guide, book or course |

## Install

```bash
claude plugin install lab-instructor --marketplace MuathIbnHassan/by-hand
```

Or inside Claude Code: `/plugin marketplace add MuathIbnHassan/by-hand`, then `/plugin install lab-instructor@by-hand`.
